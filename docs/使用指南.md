# 全球金融数据看板 · 使用指南

> 面向日常使用者：怎么装、怎么启动、界面怎么用、每个按钮干什么、出问题怎么办。
> 架构与数据源的技术细节见 [项目说明](项目说明.md)，每个数据接口的详细参数与格式见 [数据源说明](数据源说明.md)。

## 1. 环境要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 7+ / macOS / Linux（Windows 有双击启动脚本） |
| Python | 3.8 及以上 |
| 依赖 | `requests`（必须）、`openpyxl`（可选，用于 Excel 导出） |
| 浏览器 | Chrome / Edge / Firefox 等现代浏览器 |
| 网络 | 需能访问国内站点；**建议关闭系统代理或使用直连**（后端已强制不走系统代理，一般无感） |

> 无需 Node.js、无需数据库、无需任何 API Key。

## 2. 安装与启动

### 2.1 Windows（最简单）

1. 安装 Python：到 [python.org](https://www.python.org/downloads/) 下载，安装时**勾选 "Add Python to PATH"**。
2. 打开命令行安装依赖（只需一次）：
   ```
   pip install requests openpyxl
   ```
3. **双击项目目录里的 `启动.bat`**：
   - 自动寻找可用的 Python（`py -3` → `python` → 常见安装路径）
   - 启动本地服务
   - 2 秒后自动用默认浏览器打开 `http://127.0.0.1:8770/`

关闭方式：直接关掉那个命令行窗口即可。

### 2.2 macOS / Linux

```bash
pip3 install requests openpyxl
cd global-finance-dashboard
python3 server.py
```
然后浏览器打开 <http://127.0.0.1:8770/>。

### 2.3 改端口

编辑 `server.py` 末尾（或设置环境变量 `GFD_PORT`）：

```python
PORT = 8770   # 改成想要的端口
```

### 顶栏按钮

| 按钮 | 功能 |
|------|------|
| 状态文字 | 显示「更新于 HH:MM:SS · 耗时 x.xs」，失败时提示失败板块数 |

### 板块标题栏（点它=折叠/展开）

- `⣿` 图标：**按住拖动**可调整板块顺序（自动记忆）
- **圆形箭头按钮**：折叠状态指示——展开时箭头**朝下**，折叠时**朝右**；鼠标移上去会**变成蓝色并微微放大**，一眼就能看出这里可点
- 序号角标：当前板块顺序
- 右侧摘要：该板块的关键数字（如美/中 10 年期收益率）
- 最右「数据源：xxx」：**可点击链接**，直达上游页面

### 二级分类标题栏（同样可点=折叠/展开）

每个板块内部的**每一个分组**（如汇率的「美元兑换牌价」「全部货币对」及 13 个币种分组、世界股市的各个区域、美债的图表与明细表、央行利率的表格与对比图…）都是**独立可折叠**的：

- 分组标题左侧同样有**圆形箭头按钮**，点击整行即可收起 / 展开该分组
- 折叠状态**独立记忆**（键 `gfd.gclosed.v1`），刷新后保持
- 标题行里的搜索框、按钮、源码链接**不受折叠影响**，可以正常点击与输入
- 两级折叠互不干扰：折叠整个板块时，其内部各分组的折叠状态保持不变

### 页脚

- **数据源清单**：16 类用途 × 22 个上游站点的完整链接表，点击任一条直达；点标题可收起/展开。
- **作者信息**：设计：公歧子 ｜ 微信：gongqizi0

## 4. 各板块操作说明

### 4.1 汇率行情

1. 顶部「**美元兑换牌价**」区：29 个币种的 1 美元兑换价，**点击任意卡片**即在下方展开 K 线图。
2. 「**全部货币对**」区：共 191 个货币对。
   - 搜索框：输入中文名 / 代码（如 `日元`、`jpy`）即时过滤，搜索时自动忽略分组限制。
   - 分组按钮（美元/欧元/日元/英镑/澳元/加元/瑞士法郎/新西兰元/港元/新加坡元/人民币/离岸人民币/其他货币）：点击切换分组。
3. **K 线面板**：点卡片展开后可切 `分时 / 日K / 月K`；点 `正/反向` 把 USD/CNY 换成 CNY/USD（图表虚线为前收盘参考线）。

### 4.2 世界股市行情

1. 「区域筛选」按钮：**全部 / 中国 / 亚太 / 欧洲 / 美洲**（共 4 个区域分组）。
2. 点击指数卡片 → 展开日K（可切分时、月K），K 线带 MA5 / MA20 均线与底部缩放条。
3. **「中国」分组已包含 10 个指数**：中国内地上证 / 深证 / 沪深300 / 创业板 / 科创50 / 中小100，**中国香港恒生指数 / 恒生中国企业指数 / 恒生香港中资企业指数**，以及中国台湾加权指数。
4. 内地与中国香港走新浪（实时）+ 腾讯（K线 / 分时），中国台湾及其余区域走金投网——每组标题右侧都标了具体来源。

### 4.3 美股三大指数与指数期货

- 上半区：道琼斯 / 纳斯达克 / 标普500（金投网源）。

## 6. 数据说明

- **刷新频率**：手动刷新即时；自动刷新 30 秒。后端对各源有 15 秒~30 分钟不等的缓存，避免高频打上游。
- **交易时间**：非交易时段（如美股盘前、周末）部分品种涨跌为 0 或显示最近收盘价，属正常。
- **「暂无数据」**：上游休市 / 接口波动。看板会自动回退到最近一次成功缓存；若缓存也没有才显示提示。
- **涨跌颜色**：涨=红、跌=绿、平=灰（A股习惯）。

## 7. 常见问题 FAQ

**Q1：双击 `启动.bat` 窗口一闪就没了？**
命令行里运行 `python server.py` 看报错。最常见是缺依赖：`pip install requests`。

**Q2：页面一直「正在加载…」？**
看命令行窗口是否在报连接错误。个别上游可能被你的网络环境拦截——本程序已强制不走系统代理，如果你在路由器层有代理，尝试换网络。

**Q3：Excel 下载下来是 CSV 文件？**
没装 `openpyxl`：`pip install openpyxl` 后重启服务即可。

**Q4：下载的 Excel 打开乱码 / 文件名乱码？**
程序已按 RFC 5987 处理中文文件名（`filename*=UTF-8''...`），Chrome/Edge/Firefox 均正常；若用旧版 IE 可能显示 ASCII 文件名，内容不受影响。

**Q5：某个板块显示「加载失败：…」？**
把鼠标移到红色提示上看具体原因，多数是某上游临时抽风；点顶栏「刷新」重试。若长期失败，见 [项目说明 · 已知限制](项目说明.md#9-已知限制)。

**Q6：虚拟币为什么没有分时？**
新浪与 Gate.io 的现货接口都不提供分钟级历史 K 线，故该 tab 置灰。这不是故障。

**Q7：全球股指数据好像比券商软件慢一点？**
金投网全球指数为网页行情口径（与 quote.cngold.org 一致），非交易所直连，约 15 分钟级延迟。

**Q8：换电脑后板块顺序/折叠状态还在吗？**
不跨设备。这些状态存在浏览器 localStorage 里，跟设备走。

**Q9：能同时开几个？**
可以，但换端口（`GFD_PORT`），否则第二个会端口冲突。

**Q10：手机能看吗？**
可以。浏览器访问局域网内运行机器的 IP（需按下面第 8 节改监听地址），界面已适配窄屏（导航按钮变每行 2 个）。

## 8. 部署到局域网或服务器

默认只监听 `127.0.0.1`（仅本机可访问）。想让局域网其它设备访问：

```python
# server.py 末尾
srv = ThreadingHTTPServer(("0.0.0.0", PORT), Handler)   # 127.0.0.1 → 0.0.0.0
```

然后防火墙放行端口，其他设备访问 `http://<本机IP>:8770/`。

**公网部署请注意**：
- 本项目**没有鉴权**，公网暴露前请自行加反代 + Basic Auth / IP 白名单；
- 上游接口按「个人学习用途」的请求频率设计，公网多人共用容易被封 IP；
- 建议仅在内网 / 家庭环境使用。

## 9. 二次开发指引

### 9.1 新增一个汇率货币对
在 `server.py` 的 `FX_PAIRS` 里加一行（新浪代码，名称，基准币，报价币，分组）：
```python
("fx_sxxxkzt", "美元/哈萨克斯坦坚戈", "USD", "KZT", "其他货币"),
```
保存后重启即可，前端分组与搜索自动生效。

### 9.2 新增一个全球股指
在 `IDX_GL` 里加 `(金投网JO代码, 名称, 国家, 区域)`。金投网代码可在 [quote.cngold.org/gp/hqgz.html](https://quote.cngold.org/gp/hqgz.html) 页面源码里按 `JO_` 搜索。

### 9.3 新增一个板块
1. `server.py`：写 `fetch_xxx()` 返回 `{"ok":..., "items":[...]}`，在 `_api()` 里注册路由。
2. `static/index.html`：
   - 在 `SECTIONS` 加 `{id, title, srcs:[...], open}`（`srcs` 用于自动标注数据源链接）
   - 写 `loadXxx()` 渲染函数，加进 `LOADERS`
3. 无需其它改动：导航按钮、折叠、拖动、数据源标注全部自动获得。

### 9.4 更换某个数据源
所有上游都集中在 `server.py` 顶部的 `HEAD_*` 请求头与各 `fetch_*` 函数里，`docs/项目说明.md` 第 5 节有每个函数对应的上游与实测记录。
