## 2. 新浪财经

新浪是本项目覆盖面最广的数据源，共 6 类数据、5 个接口域。

### 2.1 汇率实时行情（191 个货币对）

| 项 | 值 |
|----|----|
| 页面 | <https://finance.sina.com.cn/money/forex/hq/USDCNY.shtml> |
| 接口 | `https://hq.sinajs.cn/list=fx_susdcny,fx_seurusd,...` |
| 方法 | GET，一次最多批量 ~50 个代码 |
| 请求头 | `Referer: https://finance.sina.com.cn/`（**必须**，否则返回空） |
| 返回格式 | JS 变量文本：`var hq_str_fx_susdcny="美元/人民币,7.1234,7.1250,..."` |
| 字段 | `名称, 最新价, 昨收, 今开, 最高, 最低, ...` |
| 覆盖 | 东方财富「外汇全部」同口径 191 个货币对，含人民币篮子（USD/CNY、EUR/CNY…）与交叉盘（EUR/USD、USD/JPY…） |
| 代码位置 | `server.py` → `FX_PAIRS` 表 + `sina_hq()` |

### 2.2 汇率日K / 分时

| 项 | 值 |
|----|----|
| 接口（日K） | `https://vip.stock.finance.sina.com.cn/forex/api/jsonp.php/var%20a=/ForexService.getDayKLine?symbol=fx_susdcny` |
| 接口（分时） | 同域 `.../ForexService.getMinKLine?symbol=fx_susdcny` |
| 返回格式 | JSONP，需剥离 `var a=...;` 外壳后 `json.loads` |
| 说明 | 月K由日K在前端按自然月聚合；反向（如 CNY/USD）由前端把收盘价取倒数生成 |
| 代码位置 | `fetch_fx_kline_day()` / `fetch_fx_kline_min()` |

### 4.2 各国央行基准利率（28 国）

| 项 | 值 |
|----|----|
| 页面 | <http://calendar.cngold.org/rate.htm> |

## 5. Gate.io

| 项 | 值 |
|----|----|
| 官方文档 | <https://www.gate.io/docs/developers/apiv4/> |
| 接口 | `https://api.gateio.ws/api/v4/spot/candlesticks?currency_pair=BTC_USDT&interval=1d&limit=1000` |
| 参数 | `interval`：`5m`（分时）/ `1d`（日K）/ `7d`（作月K聚合基准）；`limit` 最大 1000 |
| 分时实现 | 拉 `interval=5m&limit=288`（288 × 5 分钟 = 24 小时），按**北京时间**（`gmtime(ts + 8*3600)`）切出当日 0 点之后的点；若当前北京时间不足 12:00 且点数过少，回退为最近 24 小时 |
| 昨收基准 | 取当日第一根 5 分钟线的开盘价，或日K前一日收盘 |
| 为什么用它 | 新浪 `BtcService.getDayKLine` 已下线返回空；币安/OKX 大陆不可达；Gate.io 无需 Key 且大陆可直连 |
| 代码位置 | `fetch_crypto_kline_day()` / `fetch_crypto_kline_min()` / `GATE_PAIR` 映射表 |

## 7. 美国财政部 Fiscal Data

| 项 | 值 |
|----|----|
| 数据集页 | <https://fiscaldata.treasury.gov/datasets/debt-to-the-penny/debt-to-the-penny> |
| API | `https://api.fiscaldata.treasury.gov/services/api/fiscal_service/v2/accounting/od/debt_to_penny` |
| 参数 | `?sort=-record_date&page[size]=10000`（一次拉全量约 8400 条） |
| 字段 | `record_date`、`total_pub_debt`（国债总额）、`debt_held_public`（公众持有）、`intragov_hold`（政府内部持有） |
| 衍生计算 | 服务端为每行计算 `dod`（较上一交易日）、`mom`（较上月同期，按「日期 − 30 天」二分查找最近一条 ≤ 目标）、`yoy`（较上年同期，同理 −365 天），均含绝对值与百分比 |
| 官方 API 文档 | <https://fiscaldata.treasury.gov/api-guide/> |
| 代码位置 | `debt_rows()` / `fetch_debt()` / `export_debt()` |

> 该接口为美国官方公开数据，无需 Key、无反爬、返回稳定 JSON，是全看板最可靠的一路数据。

## 8. 请求头与反爬对策

`server.py` 顶部统一定义了各源请求头（`HEAD_*` 常量）：

| 常量 | 用于 | 关键头 |
|------|------|--------|
| `HEAD_FIN` | 新浪通用 | `Referer: https://finance.sina.com.cn/` |
| `HEAD_FX` | 外汇 | `Referer: .../money/forex/hq/USDCNY.shtml` |
| `HEAD_BOND` | 全球国债 | `Referer: .../forex/globalbd/us5yt.html` |
| `HEAD_US` | 美股 | `Referer: .../stock/usstock/` |
| `HEAD_FUT` | 国际期货 | `Referer: .../futures/quotes/` |
| `HEAD_CRY` | 虚拟币 | `Referer: .../blockchain/hq.shtml` |
| `HEAD_CM` | 中国货币网 | `Referer: .../chinese/bkrmbidx/` |
| `HEAD_JJH` | 金投网 | `Referer: https://quote.cngold.org/gp/hqgz.html` |
| `HEAD_CNG` | 金投网日历 | `Referer: http://calendar.cngold.org/rate.htm` |
| `HEAD_TX` | 腾讯 | `Referer: https://gu.qq.com/` |

三项通用对策：

1. **`Referer` 校验**：新浪全系列与金投网都校验 Referer，缺失返回空体或 403；
2. **UA 伪装**：统一使用真实 Chrome UA；
3. **不走系统代理**：`requests(trust_env=False)`，避免本机代理（如 Clash）把国内站点代理出去反而失败，且保证与浏览器直连行为一致。

## 9. 缓存策略

| 数据类型 | TTL | 说明 |
|----------|-----|------|
| 实时行情（汇率/指数/虚拟币/期货/国债） | 15 ~ 20 秒 | 与页面上限 30 秒自动刷新匹配 |
| 人民币汇率指数 | 10 分钟 | 官方每日更新 |
| 日K / 月K | 5 ~ 30 分钟 | 盘中缓慢变化 |
| 美国国债全量 | 30 分钟 | 官方每日更新一次 |
| 央行利率 | 1 小时 | 随议息会议更新 |

缓存为进程内存字典（重启即重建）；上游超时（默认 10 秒）或解析失败时，返回**最近一次成功缓存**，页面显示「暂无数据 + 原因」而非报错白屏。

## 10. 已淘汰的候选数据源

以下源在选型时实测过但被淘汰，记录在此供二次开发参考，避免重复踩坑：

| 候选 | 淘汰原因 |
|------|----------|
| 东方财富 `push2.eastmoney.com` | 本地网络持续拦截，curl / requests / 浏览器 fetch 均失败（仅静态参考其品种代码表） |
| 雪球 `xueqiu.com` | 返回「请求异常已被安全策略拦截」 |
| 同花顺 | 502 |
| stooq.com | 返回 HTML 而非数据 |
| Yahoo Finance | JSONDecodeError（返回页被篡改） |
| 新浪 `BtcService.getDayKLine` | 虚拟币历史 K 线接口已下线，返回空 |
| 币安 / OKX | 中国大陆网络不可达（ConnectTimeout） |
| BIS 央行利率接口 | 返回 `NaN` 导致 JSON 非法，且覆盖国家少 |
| akshare | 依赖重、部分接口同样走东财被拦 |
