# 全球金融数据看板 · 项目说明

> 本文档面向想了解 / 二次开发本项目的人，讲清楚：架构是什么、数据从哪来、代码怎么组织、踩过哪些坑。
> 操作层面的内容见 [使用指南](使用指南.md)。

---

## 1. 项目简介

**全球金融数据看板**是一个运行在本地的单页金融行情聚合应用：

- **后端**：`server.py`（单文件 Python，约 1350 行），用标准库 `http.server` 起一个本地 HTTP 服务，同时充当**抓取代理**——去新浪、金投网、中国货币网、美国财政部等公开数据源取数，清洗后以 JSON 吐给前端。
- **前端**：`static/index.html`（单文件，约 1250 行，内嵌 CSS/JS），用原生 JavaScript + ECharts 渲染 9 个行情板块。
- **无任何中间件**：没有数据库、没有消息队列、没有构建步骤。缓存放在进程内存里，重启即重建。

为什么需要后端代理？因为新浪、中国货币网、金投网、美国财政部等站点**均不允许网页直接跨域调用**（无 CORS 头，部分接口还校验 Referer）。浏览器直连会被拦，所以由 Python 侧代取。

---

## 2. 设计目标

| 目标 | 实现 |
|------|------|
| 真实数据，绝无占位假数 | 每条数据都来自实测可用的公开接口；取不到时明确显示「暂无数据」及原因 |
| 来源可追溯 | 板块标题栏、每个二级分类、每张 K 线图、页脚清单，四层均标注数据源并附可点击链接 |
| 网页不要过长 | 板块可折叠（状态持久化）、可拖动排序、顶部每行 4 个导航按钮直达 |
| 单机零依赖部署 | 只要 Python + requests，双击即用 |
| 符合国内使用习惯 | 涨红跌绿、人民币排前、主要货币/国家排前、中文界面 |

## 3. 整体架构

```
┌────────────────────────────┐
│  浏览器  static/index.html │
│  原生 JS + ECharts 5.5.0   │
└─────────────┬──────────────┘
              │  fetch /api/*（同源，无跨域）
┌─────────────▼──────────────────────────────┐
│  server.py  ThreadingHTTPServer :8770      │
│  ┌────────────┐  ┌────────────┐            │
│  │ 路由分发    │  │ 内存缓存    │  TTL 15s~30min
│  └─────┬──────┘  └─────┬──────┘            │
│  ┌─────▼───────────────▼──────┐            │
│  │ 抓取层 requests(trust_env=F)│  ← 不走系统代理
│  └─────┬──────────────────────┘            │
└────────┼───────────────────────────────────┘
         │ HTTPS（带 UA / Referer 伪装浏览器）
   ┌─────▼──────────────────────────────────────┐
   │ 上游：新浪 hq.sinajs.cn                     │
   │      vip.stock.finance.sina.com.cn          │
   │      bond.finance.sina.com.cn               │
   │      w.sinajs.cn（虚拟币实时）               │
   │      stock.finance.sina.com.cn（期货历史）    │
   │      腾讯 web.ifzq.gtimg.cn                  │
   │      金投网 api.jijinhao.com                 │
   │      金投网 calendar.cngold.org              │
   │      中国货币网 chinamoney.com.cn            │
   │      美国财政部 api.fiscaldata.treasury.gov  │
   │      Gate.io api.gateio.ws                   │
   └─────────────────────────────────────────────┘
```

**线程模型**：`ThreadingHTTPServer` 每请求一线程；首页加载时前端用 `Promise.allSettled` 并发请求 9 个板块接口，后端各板块内部再用 `ThreadPoolExecutor` 并发抓取上游（如国债 35 国并行）。

### 4.2 美股三大指数与指数期货

- **三大指数**：道琼斯（`JO_61864` / `.DJI`）、纳斯达克（`JO_38733` / `.IXIC`）、标普500（`JO_38732` / `.INX`）——实时与历史均走金投网（新浪美股接口已不稳定）。
- **指数期货**：道指期货 YM、纳指期货 NQ、标普500 期货 ES（CME 连续合约）——实时走新浪 `hf_YM` 等，历史走新浪 `GlobalFuturesService`。
- 点击指数或期货卡片均可展开 分时 / 日K / 月K。

### 4.3 汇率行情（191 个货币对）

- **品种来源**：覆盖东方财富「外汇中心-全部」的品种清单，代码全部映射为新浪 `fx_s***` 格式（如 `fx_susdcny`）。
- **分组**：美元 / 欧元 / 日元 / 英镑 / 澳元 / 加元 / 瑞士法郎 / 新西兰元 / 港元 / 新加坡元 / 人民币 / 离岸人民币 / 其他货币，共 13 组；顶部「美元兑换牌价」区默认展示 1 美元能兑多少各币种。
- **交互**：分组 chips 筛选 + 关键字搜索（搜索时忽略分组限制）；卡片点击展开 分时 / 日K / 月K；汇率支持**正/反向**切换（USD/CNY ↔ CNY/USD）。
- **数据源**：
  - 实时：`hq.sinajs.cn/list=fx_s***`（页面 [finance.sina.com.cn/money/forex/hq/USDCNY.shtml](https://finance.sina.com.cn/money/forex/hq/USDCNY.shtml)）
  - 日K：`vip.stock.finance.sina.com.cn/forex/api/jsonp.php/.../ForexService.getDayKLine`（1000 根）
  - 分时：同上 `getMinKLine`（只保留最后一个交易日）
  - 月K：由日K按自然月聚合（首开 / 末收 / 期间最高最低）

### 4.4 人民币汇率指数（中国货币网）

- CFETS 人民币汇率指数、BIS 货币篮子指数、SDR 货币篮子指数。
- 当前值 + 较上期 bp 变动：`chinamoney.com.cn/r/cms/www/chinamoney/data/fx/rmb-idx.json`
- 历史曲线（三线同图）：`chinamoney.com.cn/ags/ms/cm-u-bk-fx/RmbIdxChrt?indexType=3/2/1`
- 页面：[chinamoney.com.cn/chinese/bkrmbidx/](https://www.chinamoney.com.cn/chinese/bkrmbidx/)

### 4.5 世界各国国债收益率

- **美国**：1个月～30年共 13 个期限；**中国**：1年～30年共 9 个期限；**主要国家**：日/德/英/法/意/加/澳/韩等 35 项（10年期为主），每张卡片以**国家/地区名为主标题**、「10年期」作小标签，一眼可辨归属。
- 实时：新浪 `hq.sinajs.cn/list=globalbd_us10yt`（页面 [stock.finance.sina.com.cn/forex/globalbd/us10yt.html](https://stock.finance.sina.com.cn/forex/globalbd/us10yt.html)）
- 分时 / 日K：`bond.finance.sina.com.cn/hq/gb/daily?symbol=us10yt`（注意：该接口只认**不带 `globalbd_` 前缀**的裸代码）
- 美债 / 中债还各有一条收益率曲线图（按期限排横轴）。

### 4.6 美国国债数据（Debt to the Penny）

- 来源：美国财政部官方 API `api.fiscaldata.treasury.gov/.../od/debt_to_penny`，一次拉全量（`page[size]=10000`），共 **8405 条**（1993-04-01 至今，逐日）；字段取 `tot_pub_debt_out_amt`（总额）、`debt_held_public_amt`（**公众持有**）、`intragov_hold_amt`（**政府内部持有**）。
- **三类对比**（后端 `_attach_cmp()`，随每行返回）：
  | 字段 | 含义 | 参照日选取规则 |
  |---|---|---|
  | `dod` / `dodP` / `dodDate` | 较**上一交易日** | 序列中的前一条（跨周末自然落到上一交易日） |
  | `mom` / `momP` / `momDate` | 较**上月同期** | 日期 −30 天，取 ≤ 目标日的最近一条 |
  | `yoy` / `yoyP` / `yoyDate` | 较**上年同期** | 日期 −365 天，取 ≤ 目标日的最近一条 |

  每类均给出**绝对值（美元）、百分比、参照日**；`bisect` 二分查找，全量 8405 行一次性算好并随缓存复用。
- **页面顺序**：① 对比指标卡（最新总额 + 三类变化） → ② **走势图** → ③ 逐日明细表。图表与数据比较**放在明细表之前**。
- **走势图**：三条曲线（国债总额 / 公众持有 / 政府内部持有），**数据类型按钮**与 ECharts 图例均可单独开关（至少保留一条）；**时间范围**可选 近 3 个月 / 1 年 / 3 年 / 5 年 / 10 年（后端一次返回 2600 个交易日，约 10 年）。
- **明细表**：分页（每页 10 / 20 / 100 条可切换，共 841 页 @20 条），列含日期、总额、公众持有、政府内部持有、万亿美元换算、**较上日 / 较上月同期 / 较上年同期**（涨红跌绿）。
- **全量 Excel 下载**：后端 `openpyxl` 生成 xlsx（14 列，含三类对比列与参照日；实测约 400 KB / 8405 行）；未装 openpyxl 时自动降级为 CSV，文件名带 `Content-Disposition` 中文文件名（RFC 5987）。

### 4.7 各国央行利率

- 来源：金投网财经日历 `calendar.cngold.org/rate/readmore/{1,2}.html`（直接返回 JSON 数组，页面 [calendar.cngold.org/rate.htm](http://calendar.cngold.org/rate.htm)）。
- 28 个国家 / 地区，主要经济体排前（美 / 欧元区 / 中 / 日 / 英…）。
- 字段：利率名称、当前值、前次值、变动（bp）、公布日期。
- 附加「**主要国家利率水平对比**」——ECharts **横向柱状图**（前 18 个国家 / 地区，y 轴按利率从高到低，柱上直接标数值，颜色分档：≥5% 深红、≥3% 橙、≥1% 蓝、>0 绿），鼠标悬停显示利率名称、前值、变动、公布日期；支持滚轮 / 捏合缩放。
- 表格与对比图各自独立折叠，互不影响。

### 4.9 虚拟币行情（12 个币种）

- **实时**：新浪 `w.sinajs.cn/?list=btc_***`（页面 [finance.sina.com.cn/blockchain/hq.shtml](https://finance.sina.com.cn/blockchain/hq.shtml)）
- **日K / 月K**：**Gate.io 现货 K 线** `api.gateio.ws/api/v4/spot/candlesticks`（1000 根日线，月K聚合）。
  > 为什么用 Gate.io：新浪的虚拟币历史 K 线接口已下线（`BtcService.getDayKLine` 返回空）；币安 / OKX 在大陆网络不可达；Gate.io 的 API 域 `api.gateio.ws` 可直连且免鉴权。
- **分时**：Gate.io 同样的现货接口，`interval=5m&limit=288`，后端按**北京时间**切出最近一个自然日（00:00 起），不足 12 个点则回退「最近 24 小时」；另取 `interval=1d&limit=2` 的上一根日线收盘价作为分时图的**基准线（昨收）**，由接口字段 `ref` 返回。
- 代码映射：新浪 `btcbtcusd` ↔ Gate.io `BTC_USDT`（见 `GATE_PAIR`）；时间戳统一用 `time.gmtime(ts + 8*3600)` 转北京时间，不依赖本机时区。

## 6. 后端实现要点

### 6.1 缓存与降级

```python
cached(key, ttl, producer)   # 带 TTL 的内存缓存
peek(key)                    # 忽略 TTL 取上一份成功数据
```
- 实时行情 TTL 15~20s；K线 600s；美债全量 1800s。
- 抓取失败时先 `peek()` 回退上一份可用数据，前端永不空白；彻底没有才返回 `ok:false + error`。

### 6.2 反爬对策

- `requests.Session(trust_env=False)`：**不走系统代理**（本机代理常把国内站点劫持出 502）。
- 每个站点配独立的 `Referer`（如新浪债券接口必须带 `stock.finance.sina.com.cn` 的 Referer，否则空返回）。
- 新浪 `hq.sinajs.cn` 返回 **GBK**，统一按 GBK 解码。
- JSONP 响应（`jsonp.php/var a=(...)`）用 `jsonp_payload()` 剥壳。

### 6.3 数据清洗

- `fnum()`：安全转 float，`NaN`/`Inf` → `None`（BIS 教训）。
- `clean_json()`：递归清洗整个响应树，保证 `json.dumps` 输出永远是合法 JSON。

### 6.4 K 线统一出口

```python
KLINE_MAP = {
  "fx":       (fetch_fx_kline_day,      fetch_fx_kline_min),
  "bond":     (fetch_bond_kline_day,    fetch_bond_kline_min),
  "index":    (fetch_index_kline_day,   fetch_index_kline_min),
  "us":       (fetch_index_kline_day,   fetch_index_kline_min),
  "crypto":   (fetch_crypto_kline_day,  fetch_crypto_kline_min),
  "futures":  (fetch_futures_kline_day, fetch_futures_kline_min),
}
fetch_kline(kind, code, typ)  # typ: min / day / month
```
- `period_wrap()` 统一包装：`day` 直接返回；`min` 经 `last_day()` 只留最后一个交易日（避免分时混入多日）；`month` 经 `to_month()` 由日K按自然月聚合。
- **债券**代码需去 `globalbd_` 前缀再请求 `bond.finance.sina.com.cn`。

## 7. 前端实现要点

- **单文件 SPA**：无框架、无构建，原生 JS；ECharts 5.5.0 本地化到 `static/vendor/`，**离线也能用**。
- **板块骨架**：`SECTIONS` 定义 9 个板块 → `buildShell()` 生成 DOM → `getOrder()/getClosed()` 从 localStorage 恢复顺序与折叠状态。
- **折叠（两级）**：
  - 一级：点击板块标题栏 toggle `.closed`（`.sec.closed .sec-body{display:none}`），状态写入 `gfd.closed.v2`。箭头为 **CSS 画在圆形底衬上的加粗箭头**（`.sec-head .chev`，悬停变主题蓝并放大），展开朝下、折叠朝右。
  - 二级：每个分组用 `grp(key, title, right, body)` 包成 `<div class="grp">`，点击 `.grp-title` toggle `.closed`（`.grp.closed .grp-body{display:none}`），状态写入 `gfd.gclosed.v1`；`setBody()` 重绘后自动 `bindGrp()` 重新绑定（含事件排除：标题行内的链接 / 按钮 / 输入框不触发折叠）。
  - 展开时对内部图表调用 `resizeChartsIn()`（初始化时可能处于 `display:none`，尺寸为 0；`bindResize()` 同时监听窗口 resize 与所属板块标题点击）。
- **拖动**：HTML5 Drag & Drop，`dragover` 里按鼠标 Y 与板块中线比较决定插到前方还是后方，`dragend` 时把 DOM 顺序写回 `gfd.order.v3`，并重建顶部导航按钮。
- **图表面板**：`toggleChart()` 在卡片后插入 `.chart-panel`（同一时刻只允许一个，`openPanel` 记录状态）；面板内 分时/日K/月K tab + 汇率专用「正/反向」按钮；`drawCandle()` 含 MA5/MA20 与 `dataZoom` 缩放。
- **主题**：CSS 变量双主题（`data-theme="dark"`），切换后重绘图表坐标轴颜色。
- **涨跌配色**：涨红跌绿（A股习惯），`.up{color:var(--up)}`。
- **数据源标注组件**：`slinks(list)` 把 `{名称, 链接}` 数组渲染成可点击链接，被四处复用：板块标题栏 `.src`、二级分类 `.gsrc`、K 线面板 `.cp-src`、页脚 `#srcGrid`。

## 8. 接口文档

### GET /api/fx
```jsonc
{ "ok": true, "items": [
  { "code": "fx_susdcny", "name": "美元/人民币", "base": "USD", "quote": "CNY",
    "group": "人民币", "price": 7.1234, "prev": 7.1258, "change": -0.0024,
    "pct": -0.03, "ok": true } ] }
```

### GET /api/kline?kind=fx&code=fx_susdcny&type=day
```jsonc
{ "ok": true, "type": "day", "code": "fx_susdcny",
  "data": [ { "d": "2026-09-01", "o": 7.12, "l": 7.10, "h": 7.15, "c": 7.13 } ] }
```
- `type=min` 时元素为 `{ "t": "09:30", "v": 7.123 }`
- `kind` ∈ `fx / bond / index / us / crypto / futures`

### GET /api/debt?page=1&size=20
```jsonc
{ "ok": true, "page": 1, "size": 20, "pages": 841, "total": 8405,
  "oldest": "1993-04-01", "latest": { "date": "2026-10-01", "total": 4.0261e13 },
  "rows": [ { "date": "2026-10-01", "total": 4.0261e13,
              "public": 2.89e13, "intragov": 1.13e13 } ] }
```

### GET /api/rates
```jsonc
{ "ok": true, "items": [
  { "country": "美国", "name": "联邦基金利率", "cur": 4.0, "prev": 4.25,
    "bp": -25, "bpText": "-25bp", "date": "2026-09-17", "ok": true } ] }
```

其余接口字段同构（`ok` + 业务字段 + `error`），从 `/api/ping` 可做健康检查。

## 9. 已知限制

| 限制 | 说明 |
|------|------|
| 虚拟币无分时 | 新浪 / Gate.io 现货接口均不提供分钟级历史，面板中该 tab 置灰 |
| 部分国债品种无数据 | 35 项主要国家国债中实测 29 项有数据，其余上游本身不提供 |
| 金投网全球指数延迟 | 与其官网一致（约 15 分钟级），非交易所直连 |
| 上游改版风险 | 各源均为非官方开放接口，字段变更需改 `server.py` 对应解析函数 |
| 仅支持本机/局域网 | 默认监听 `127.0.0.1`；公网部署请自行加鉴权与反代 |
